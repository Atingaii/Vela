# 平台后续规划

当前只交付 macOS：先完成与固定 Codenotch Swift 基准一致的功能、界面和交互，并验证 Apple Silicon / Intel 的实际安装与更新。完整验收保持进行中，见 [迁移核对表](migration-parity.md) 和 [ADR 0009](adr/0009-macos-first-delivery.md)。

| 平台 | 当前状态 | 收到用户明确启动指示后再做 |
| --- | --- | --- |
| Windows | 暂缓；保留既有适配代码和历史证据，不继续打包或验收 | 按已验收的 Mac 行为核对窗口、托盘、凭据和会话隔离；恢复 Windows CI；验证 NSIS 安装、更新和实机交互 |
| Linux | 仅规划，没有受支持的客户端交付 | 先确认目标发行版与桌面环境，再核查窗口吸附、系统托盘、凭据库与 WebKit 兼容；实现并验证安装、更新和真实桌面交互 |

以上没有自动启动时间，也不因 macOS 完成而自动进入开发。历史 Windows 下载包不代表本阶段继续维护或已达到完整迁移标准。共享代码中已有的平台分支保留，不为暂停平台工作进行无关重构。
