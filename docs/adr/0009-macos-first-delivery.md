# ADR 0009：先完成 macOS，其他平台等待明确启动

状态：Accepted（2026-09-23，实施与验收进行中）

## 背景

用户明确收窄当前阶段：先确保 macOS 满足完整迁移目标，其他平台仅写入规划，收到新的明确指示后再实施。继续把其他平台构建、适配和安装问题作为本阶段门槛，会分散原生 Mac 界面与实际使用验收的投入。

## 决策

当前交付仅包含 macOS，保留 Apple Silicon 与 Intel 两种 Mac 架构。固定 Swift 基准、Tauri 2 / Rust / WebView 技术路线以及全部 UI、视觉、交互和业务语义的迁移要求不变。

日常原生 CI、DMG 发布和真实签名升级验证只运行两种 macOS runner。浏览器回归可继续在 Ubuntu runner 上执行；这只是测试环境，不表示开发或交付 Linux 客户端。预览 feed 只包含两种 darwin 平台，任何一份 Mac 更新资产或签名缺失都不能发布。

Windows、Linux 进入[平台后续规划](../platform-roadmap.md)，不继续适配、构建安装包或执行平台专项验收。已存在的兼容代码、历史包与证据保留，但不据此宣传为本阶段受支持的交付。恢复工作必须由用户明确启动，不因 macOS 阶段完成自行推进。

Mac 阶段仍须完成真实原生界面和交互对照、安装后的启动及签名更新验证。源码检查、浏览器 fixture、原生启动 smoke 分别报告；锁屏或缺少真实账户时对应验收保持未完成，不能降低标准。没有 Apple Developer 账号时继续明确标注未公证预览和单应用首次打开步骤。

## 影响与恢复条件

本记录取代 [ADR 0006](0006-full-swift-parity-before-product-changes.md) 的当前跨端实施范围，以及 [ADR 0007](0007-velo-preview-distribution.md)、[ADR 0008](0008-signed-preview-updates.md) 的三平台同步发行条件；这些记录的其他技术与信任决策继续适用。恢复其他平台时再补回目标平台测试、安装验证及 feed 资产，不能仅打开矩阵后直接宣称完成。

本决定减少本阶段的验证范围，没有删除原版 Mac 功能，也没有把尚未通过的 Mac 界面验收标成完成。
