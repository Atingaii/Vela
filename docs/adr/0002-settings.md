# ADR-0002 · 设置收敛与按需工具窗口

- 状态：Accepted
- 日期：2026-09-22

用户要求迁移后再精简，保持原交互。本轮保留侧栏设置结构；外观保留显示方式、三档大小、四边、条件显示的多屏选择与复位。移除周环内外位置、重复移动把手开关、隐藏托盘图标等低频控制；底层周用量仍在悬浮卡片可读，拖动与边缘切换保留。

语言移至通用。通知只提供“等待回应”“任务完成”，默认关闭；声音与送达行为跟随操作系统。只在状态变化时通知，重复快照去重；拒绝权限或保存失败时不呈现成功状态。

新增工具放在按需创建的独立窗口，从吸附栏右键和设置进入。避免把供应商表单、账期和插件权限全部塞回外观设置；关闭后释放该 WebView，不进行工具后台轮询。
