# ADR-0004 · 本地账本、估计与数据边界

- 状态：Accepted
- 日期：2026-09-22

保留上游供应商额度显示；新增本地 token 账本与其并列。账本来自默认目录的 Claude JSONL 和 Codex rollout，仅读取使用量元数据，不保存提示词正文、不上传日志。按需最多扫描 300 个日志、32 MiB、4000 个目录项与 10 层目录，达到上限明确显示不完整。

Claude 按 session/message ID 合并流式更新；Codex 由累计 token 样本差分，缓存输入从总输入中扣除，防止重复相加。按 UTC 日期、CLI、模型、项目汇总。本版 Gemini 不提供日志账本解析，其配置同步支持不代表已有日志统计支持。

金额采用用户填写的模型单价（每百万 token）和币种，不硬编码可能变化的价目表。按每月结算日计算账期，月末不足按当月末日处理。预测为已知 API 等值费用 / 已经历日数 × 账期日数；缺单价、读取不完整、无数据不出预测。固定订阅金额独立展示，不将套餐金额与其包含的 API 用量重复加总。

取舍：这是本机可见记录的估计，并非供应商实际账单。删掉的日志、其他设备、远端调用、自定义 CLI 数据目录不自动覆盖；前台已注明。本版不接 SQLite 历史仓库，避免增加后台采集和索引负担。未来若增加多设备统计或账单对账，应有新的来源与去重 ADR。
