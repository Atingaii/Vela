# ADR-0003 · 显式启停的边缘插件

- 状态：Accepted
- 日期：2026-09-22

v1 采用 `EdgePlugin` Rust trait + 静态注册表。每个插件提供稳定 ID、版本、能力列表和操作入口；同一分发命令检查启用状态后执行。内置文件中转站、剪贴板预览以同样接口接入。

选择编译期扩展而非动态原生库、无限制 JavaScript 或立即引入 WASM：当前需求是可扩展边缘工具，需要真实接口与使用路径；第三方安装和沙箱尚没有确定分发、更新、权限撤销策略。编译期插件可信任程度等同主应用，不把能力列表误称运行时沙箱。

文件只复制，不移动；明确数量和容量限制、不覆盖同名文件、不接收符号链接与目录。剪贴板只读用户点击时的文本，不保留历史。所有操作经插件开关控制，停用不删除保留的数据。

后续新增插件可实现 trait 并注册；第三方运行时安装需单独 ADR，评估 WASM、权限代理、签名与资源限制。
