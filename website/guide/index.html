FIRST LAUNCH ON MAC

提示“Apple 无法验证 Velo.app”？

当前 Mac 预览版尚未经过 Apple 公证，系统会拦截首次打开。请确认来自本官网或 GitHub Releases，并核对下载页的 SHA-256 校验文件，再按下面步骤仅允许 Velo。

  1. 点“完成”，保留应用

    先把 DMG 中的 Velo 拖入「应用程序」，打开一次。如果出现拦截提示，点「完成」。若已经移到废纸篓，请重新安装。

  2. 打开“隐私与安全”

    进入「系统设置 → 隐私与安全」，向下找到 Velo 被阻止打开的记录，点击「仍要打开」。

  3. 确认打开 Velo

    按系统提示完成密码或 Touch ID 验证，再确认打开。启动后查看顶部菜单栏或屏幕边缘，从 Velo 菜单打开「设置 → 账户」。

没有看到“仍要打开”？先尝试启动一次 Velo，再立即返回此处。受组织管理的 Mac 可能需要管理员处理。此步骤仅适用于无法验证开发者的提示；若系统明确提示恶意软件或文件损坏，请停止并反馈。

已经点了“完成”，应用是不是安装失败了？

不是。「完成」只关闭这次提示。保留「应用程序」中的 Velo，然后到隐私与安全中完成单独允许即可。无需反复下载安装包。

找不到“仍要打开”按钮？

请先从「应用程序」再次尝试打开 Velo，关掉提示后立即进入「系统设置 → 隐私与安全」，向下滚动到安全性区域。公司或学校管理的电脑可能限制该操作，需要联系管理员。

允许之后，没有看到软件窗口？

Velo 主要显示在屏幕边缘和顶部菜单栏，不是启动后弹出大窗口的应用。请点击菜单栏中的 Velo 菜单，选择「设置」，再打开「账户」；先登录你使用的 Claude Code、Codex 或 Cursor。如果仍没有菜单或屏幕边缘界面，请携带系统版本和安装包版本反馈问题。

下次启动或升级还需要重复操作吗？

对当前应用确认后，后续通常可以正常打开。重新下载安装包或升级后，macOS 可能再次要求确认；按相同流程处理，并始终从官网或 GitHub Releases 获取更新。

Apple 官方操作说明 ↗
01 / CONNECT

先登录你使用的工具

在 Claude Code、Codex、Cursor 等工具中完成登录。Velo 会按启用的集成读取本地状态或在线额度，部分服务还需要单独配置密钥。

02 / ARRANGE

把常用账户放在前面

从托盘菜单打开设置，在「账户」中选择显示的账户并调整顺序。「是否读取」与「是否显示」可以分别设置。

03 / YOUR DESKTOP

调整位置，开启提醒

在「外观」中选择屏幕边缘与大小，在「提醒」中按需开启完成或额度提醒。悬停圆环查看详细状态。

04 / SESSION STATUS

需要会话状态时，开启 hook

Claude Code 的会话状态需要在设置中显式开启对应消息 / hook 选项。这会向 Claude Code 设置文件添加向 Velo 发送状态的配置。

A FEW THINGS TO KNOW

开始之前。

Mac 提示无法验证，打不开怎么办？

这是未公证预览版的系统拦截。请按照本页上方的 Mac 首次打开步骤，在隐私与安全中对 Velo 单独选择「仍要打开」。

这是完整正式版吗？

v0.1.1-preview.1 已发布，提供 Apple Silicon 与 Intel Mac 安装包。完整功能对齐、多屏体验、原生界面与真实账户仍需进一步验证。

第一次使用，需要做什么？

先在你使用的 AI 编程工具中完成登录，安装并启动 Velo，再从托盘打开设置选择账户。部分集成需要额外配置；Claude Code 会话状态需要显式开启相应 hook。将应用拖入 Mac 的「应用程序」文件夹。

我的密钥和数据保存在哪里？

应用配置保存在本机，应用密钥保存在 macOS Keychain。第三方 CLI 登录凭据以只读方式访问。在线额度会请求对应供应商的服务。为兼容旧数据，内部配置目录暂时沿用 vela 名称。

是否有自动更新和手机连接？

公开的 v0.1.0-preview.4 不支持应用内升级到新版，请手动下载并安装 v0.1.1-preview.1。新版已接入签名自动更新。手机连接按迁移基准尚未开放，当前版本不提供启用入口。

遇到问题，如何反馈？

在 GitHub Issues 提供系统版本、安装包版本、复现步骤和预期结果。截图与日志请先移除账户信息、token、Cookie、密钥和真实会话内容。
