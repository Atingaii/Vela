GET STARTED

从第一次打开，
到安心工作。

装好 Velo 后，花几分钟让它跟上你的工作方式。

还没安装？先下载 Velo ↗
01 / CONNECT

先登录你使用的工具

在 Claude Code、Codex、Cursor 等工具中完成登录。Velo 会按启用的集成读取本地状态或在线额度，部分服务还需要单独配置密钥。

02 / ARRANGE

把常用账户放在前面

从托盘菜单打开设置，在「账户」中选择显示的账户并调整顺序。「是否读取」与「是否显示」可以分别设置。

03 / YOUR DESKTOP

调整位置，开启提醒

在「外观」中选择屏幕边缘与大小，在「提醒」中按需开启完成或额度提醒。悬停圆环查看详细状态。

04 / SESSION STATUS

需要会话状态时，开启 hook

Claude Code 的会话状态需要在设置中显式开启对应消息 / hook 选项。这会向 Claude Code 设置文件添加向 Velo 发送状态的配置。

按你的习惯安排

完整设置界面如上。各工具提供的数据与能力不同，具体覆盖范围见 功能核对表。

A FEW THINGS TO KNOW

开始之前。

这是完整正式版吗？

这是可以下载安装的开发预览版。发布流程包含自动化测试与安装后的原生设置窗口、IPC、辅助程序检查；完整功能对齐、多屏体验、全部系统版本和真实账户仍需进一步验证。

第一次使用，需要做什么？

先在你使用的 AI 编程工具中完成登录，安装并启动 Velo，再从托盘打开设置选择账户。部分集成需要额外配置；Claude Code 会话状态需要显式开启相应 hook。macOS 将应用拖入「应用程序」，Windows 按安装向导完成安装。

我的密钥和数据保存在哪里？

应用配置保存在本机，应用密钥保存在 macOS Keychain 或 Windows Credential Manager。第三方 CLI 登录凭据以只读方式访问。在线额度会请求对应供应商的服务。为兼容旧数据，内部配置目录暂时沿用 vela 名称。

是否有自动更新和手机连接？

本预览版尚未启用签名自动更新，升级请重新下载安装包。手机连接默认关闭，已有局域网加密配对协议，但真实手机互通仍在验收中。

遇到问题，如何反馈？

在 GitHub Issues 提供系统版本、安装包版本、复现步骤和预期结果。截图与日志请先移除账户信息、token、Cookie、密钥和真实会话内容。
