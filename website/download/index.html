NEXT: FIRST LAUNCH

下载后，按这个顺序打开。

  1. 打开 DMG，把 Velo.app 拖入「应用程序」。
  2. 从「应用程序」打开 Velo。若 Apple 拦截，点「完成」保留应用。
  3. 进入系统设置 → 隐私与安全 → 仍要打开，确认对 Velo 单独允许。
  4. 启动后查看屏幕边缘或顶部菜单栏，打开设置 → 账户，选择你已登录的工具。

Velo 是菜单栏 / 屏幕边缘应用，正常启动后不一定出现普通主窗口。

UP AND RUNNING

下载之后，三步开始。

  1. 安装到电脑

    Mac 打开 DMG，将 Velo 拖入「应用程序」。Windows 运行安装向导；缺少 WebView2 时需要联网安装运行时。

  2. 确认首次打开

    预览版没有 Apple 公证或 Windows 代码签名。核对来源与校验和后，Mac 按照首次打开步骤进行单独允许；Windows 按系统提示确认。

  3. 选好你的账户

    先登录使用的 AI 工具，再从 Velo 托盘打开设置，选择账户与显示位置。
