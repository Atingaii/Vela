# 方案与边界

分发行为位于发布工作流与 macOS 安全评估，不在应用 UI。复用现有 smoke，添加独立只读信任评估脚本与可运行的已发布包核查 workflow；原发布继续明确 unnotarized preview 并附信任报告，签名完整性失败必须阻断，默认分发 gate 的严模式必须拒绝未公证。开发者账号尚无，不假造证书，不关闭 Gatekeeper，不移除 quarantine，不触碰用户应用/凭据。

官网添加 /product/，清除旧的 product 重定向，页头统一产品说明、使用指南、下载。首页替换手绘 HTML 示意为当前 notch.html 界面截图；产品页详细展示账户、用量、外观、通知，指南保留操作顺序。截图通过现有 demo-bridge 注入合成数据，在浏览器渲染实际产品 HTML，2x 分辨率，不改 UI 样式；透明区域截图使用官网画布承托，不对产品图调色。清楚说明它不是原生系统/真实账户验证。

仅更改 website、文档资产与捕获脚本、分发验证脚本/工作流及相应测试规范。无需改 Rust、切栈、收费账户注册或原生 UI。
