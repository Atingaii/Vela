# README 产品介绍与品牌配图

## 目标
把面向实现者的迁移记录改为面向用户和贡献者的产品首页；用户已授权生成头图、制作截图、提交并推送 main。

## 范围
- README：定位、功能、界面预览、集成状态、源码启动、开发验证、贡献、许可、末尾致谢。
- docs/assets/readme：品牌头图及当前 HTML 界面的演示截图，配图来源与复现说明。
- 仅文档和展示素材，不修改产品功能、应用图标、依赖清单或发布版本。
- CodeNotTouch 仅在 README 最后致谢；仓库核实实际名称为 Codenotch，链接原项目并保留现有 LICENSE / THIRD_PARTY_NOTICES。

## 验收
- 头图进入仓库，GitHub 可直接显示图片；没有伪造应用实机或真实账户证据。
- 界面截图使用当前源码，明确注明模拟账户数据，不涉及私密数据。
- 已有能力与未验收能力区分；尚未公开安装包时提供源码运行方式，不编造下载按钮。
- 本地链接与资源、Markdown、图片尺寸和浏览器排版通过检查。
- 运行适用 Node / UI 检查；提交并确认远端 main 与本地一致。
- 清理本轮一次性预览及缓存，保留交付图片、复现素材与可复用依赖。
