# 官网导航与标签页图标

用户要求调研真实产品官网并优化当前仅作页内目录的导航，同时更新浏览器标签页图标。保留已有品牌、页面风格与真实安装包。

## 验收
- 页头清楚呈现品牌、独立使用指南、主要下载动作；不再使用功能/FAQ页内目录作为主导航。
- 首页专注产品介绍；下载页提供平台选择和安装说明；使用指南提供首次配置、FAQ与反馈路径。
- 原先 /#download、/#faq、/docs 访问仍能抵达相关内容。
- 桌面与320/390px移动端导航均可操作，当前页面可辨识，键盘和主题切换可用。
- 图标提供通用ICO与PNG以及Apple触屏图标，沿用产品V标识；各页面和404均引用，采用新的资源URL避免沿用旧图缓存。
- 部署现有 Cloudflare Pages velo 的生产与预览分支，检查公开页面和下载链接。

用户追加：首屏配图与网站UI不协调。用响应式、随主题变化的产品交互示意替换灰底位图卡片，明确示例数据；实际设置截图放到指南，保留产品真实性边界。
